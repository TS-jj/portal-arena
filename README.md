# 传送门战场 · PORTAL ARENA

浏览器端的 4v4 第一人称团队竞技（Three.js / WebGL）。穿越传送门瞬移包抄，率先达成 **30 次击杀**的队伍获胜。

- 玩家 + 3 名队友（苍鹰 / 岩石 / 霜刃）对阵 4 名敌人
- 桌面端：鼠标键盘 + 指针锁定；手机端：PUBG 式布局的虚拟摇杆与按键
- 单页静态站点，无构建步骤，直接托管在 GitHub Pages

## 操作

| 桌面 | 手机 |
| --- | --- |
| `WASD` 移动 · `Shift` 冲刺 | 左下摇杆移动，推到底自动冲刺 |
| 鼠标转视角 · 左键开火 | 右半屏拖动转视角 · 射击键开火 |
| 右键 / `F` 举镜 | 瞄准键举镜 |
| `空格` 跳跃 · `C` 蹲伏 / 滑铲 | 跳跃 / 蹲伏键 |
| `R` 换弹 · `1`–`4` 滚轮换枪 | 底部武器条直接点选 · 换弹键 |
| `M` 战术地图 · `ESC` 设置 | 地图图标 / 设置图标 |

## 地图标记

| 标记 | 含义 |
| --- | --- |
| 绿色箭头（内含 1） | 你自己，1 号位 |
| 蓝色圆圈 + 白色数字 2 / 3 / 4 | 队友，编号即小队位次 |
| 红色三角 | 敌人（只在视野 / 交火范围内出现，与《和平精英》一致） |
| 彩色菱形 | 传送门，颜色对应目的地 |

小地图固定显示全图；重叠的队友标记会自动错开一格（约 13px），保证编号可读。

## 横屏

网页无法强制旋转屏幕，项目做了三层处理：

1. **竖屏提示层**：手机上竖持打开会显示「请横屏游玩」，可一键请求全屏并尝试锁定横屏；也可选「继续竖屏」，此时使用简化布局，仍然可玩。
2. **全屏 + `screen.orientation.lock('landscape')`**：Android Chrome / Edge 只在全屏下允许锁定，所以锁定动作绑定在点击手势里。iOS Safari 不支持该接口，只会退化为提示。
3. **Web App Manifest**（`orientation: landscape`）：添加到主屏幕后启动即为横屏全屏。

## 本地运行

```bash
node server.js 8123     # 打开 http://127.0.0.1:8123/
```

`start.bat` 是 Windows 下的等价入口。站点为纯静态，任何静态服务器均可（注意保留 `.nojekyll`、保持文件名大小写）。

## 部署

仓库根目录即站点根目录，Pages 设置为 `main` 分支 `/ (root)`。修改后：

```bash
git add -A && git commit -m "update" && git push
```

GitHub Pages 大约 30–60 秒后生效。
